# Art prompts for 'O Sistema

Attach your **style reference image** to every request and start with "Same style as the attached reference."
Every sheet uses the same rules, so I can cut them automatically:

> A sprite sheet: a **4×4 grid of 16 equal square cells**, one item centred in each cell with empty space around it, nothing crossing the cell borders, **transparent background**, no text, no logos, no grid lines drawn. Seen **from directly above (90 degrees overhead, orthographic)** unless the prompt says otherwise. Front of every item pointing **down** (towards the viewer), all items at the same scale.

Save into `Assets/_Project/Art/` with the file name given for each sheet. Generate each sheet 2–3 times and keep the cleanest; a sheet with one bad square is fine, I'll skip that square.
